## Question and procedure

Can the native endpoint strings be associated provisionally with actual source
image token groups, and does the image support treating them as the same glyph
sequence? Distinguish that question from repeated plaintext or translation.

1. Verify the pinned source catalog, native paragraph corpus and complete parent
   boundary report. Record the selected common unit and every original member
   key, source identity, type, locator, variables and drawing counts.
2. Before image interpretation, recover both complete raw source loci and their
   conservative-adapter endpoints under split and join. Retain uncertainty
   notation and each source's actual case. Check equality within each variant
   and separately across variants; four repeat counts do not imply identical
   endpoint strings across sources or spacing policies.
3. Verify the live Yale object/image references, retrieve the official image
   locally, and record retrieval date, exact URL, byte hash, decoded dimensions
   and any difference from the recorded index. Keep all image bytes out of Git,
   PRs and attachments; publish source links and technical coordinates only.
4. Inspect full-page layout first. Record text groups, drawing interruptions,
   visible row counts and uncertainty. Never align source IDs by ordinal alone.
   For `f82r.1` through `f82r.9`, compare group geometry and several neighboring
   token-shape anchors before proposing the locations of `.3` and `.4`.
5. If a row association is supportable, retain image coordinates and an explicit
   basis for each proposed endpoint region. Use original pixels or official
   image-service zoom regions, without AI-generated replacement pixels. Record
   exact region URLs and dimensions for any inspected zoom.
6. Describe the observed shapes, gaps, possible ligatures and damaged/ambiguous
   strokes at both endpoints. Preserve alternative associations/readings. Do
   not force a glyph-to-Eva correspondence, choose a preferred source, normalize
   differences away, or correct the pinned transcriptions from one inspection.
7. Assign each row/glyph conclusion separately as unresolved, provisional, or
   supported by the stated observation. Even a locally supported shape match
   needs independent qualified review; this is one assistant's inspection with
   known source readings and expected repetition, not a blind adjudication.

## Deliverable and limits

Prepare a local source-linked observation record and readable note with input
pins, all selected unit/variant identities, source/image references, complete
uncertainties, reviewed pixel regions and exposure. Verify metadata/endpoint
facts by fresh source replay; code cannot verify a visual judgment. No native
page-wide transcription or image binary needs publication. Inspect exact
outgoing metadata and any selected native excerpt before later submission.

Encoded token equality can hide transcription conventions or different glyphs;
a visible glyph match still does not establish decoded-word equality, language,
copying, meaning, statistical independence or decipherment. A failed or ambiguous
alignment is a result to preserve. The heavily selected paragraph cohort and
post-statistic choice cannot establish how often physical repetition occurs.
