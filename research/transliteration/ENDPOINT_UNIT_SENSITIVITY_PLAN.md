## Fixed representations and measurement

Use exactly the three policies in the accepted
[unit protocol](../baselines/EVA_UNIT_PROTOCOL.md) and its
[JSON](../baselines/eva-unit-protocol.json), with the existing segmenter:

- ASCII letters: no grouped patterns.
- Bench sequences: `ch`, `Ch`, `sh`, `Sh`, `cth`, `cTh`, `ckh`, `cKh`, `cph`,
  `cPh`, `cfh`, `cFh`.
- Bench and minim sequences: that list plus `in`, `iin`, `iiin`, `il`, `iil`,
  `iiil`, `ir`, `iir`, `iiir`, `im`, `iim`, `iiim`.

Scan each original token left to right, longest match first, lexical tie
break, single-letter fallback. Never cross token boundaries or fold case.
Each segment label is its exact native substring, so concatenation must
reconstruct the token. This is a reversible analyst-defined segmentation,
not a glyph adjudication or a complete conversion to a historical alphabet.
Unlisted connected examples retain the accepted fallback behavior, including
partial matches inside their spellings; add no pattern after viewing results.

Use ordinary unit-cost Levenshtein insertion, deletion and substitution on the
**sequence of segment labels**, divided by the maximum segment count of the two
endpoints. A multi-letter segment has one edit cost, and equal labels must have
identical original spelling/case. No transposition, phonetic rule or substring
edit within a grouped label is allowed. Exact zero distance therefore retains
literal token equality. Sum with equal boundary weight and divide by 652 for
the displayed mean. The ASCII policy must reproduce every parent cost,
probability, unit moment and aggregate exactly.

last loci fixed. Preserve all native content, token boundaries and identity
multiplicity. Use the same allowed identity order simultaneously for all
representations; do not compare independent control draws. Compute exact
