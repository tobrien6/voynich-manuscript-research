# Fixed immediate-repeat image pilot

Recorded 2026-10-12, before this selector's manuscript output or new image
inspection. Contributor: this chat, authenticated GitHub account `tobrien6`.

Question: which encoded immediate self-repeats survive the paired editions and
all four uncertainty policies, and what source/image questions do stable
disagreements expose? This connects the accepted repeating-type count to
inspectable manuscript evidence. It does not create a new null statistic or
validate the source encodings as words or glyphs.

## Corpus and complete accounting

Use the accepted 3,884 shared present P0 locus keys in pinned ZL3b and IT2a,
the accepted lexer, and split/join uncertain commas crossed with exclude/first
alternative handling. Preserve original token coordinates and null excluded
positions; an excluded position interrupts adjacency. Count equal nonnull
neighbors within each original locus, including overlapping events in runs.
Keep all eight event lists for every locus with a repeat in any treatment,
and every zero-event locus key. Reconcile cohort/source/slot digests, total
event counts and globally distinct repeating representations with the accepted
`repeating_types.json`; retain native case and source notation.

## Frozen candidate and selection rules

The image pilot additionally requires both source locators to be regular
(`@`, `+`, `*`), an ordinary unsuffixed page identifier (`fN[r/v]`), exactly one
matching exact-single-side Yale canvas with neither partial nor compound
label flags, at least two apparent tokens, and no excluded token in any of
the eight treatments. Report every failure reason with original locus keys;
these filters affect image candidates only, never the accepted statistic.

Define three disjoint candidate groups:

1. **Paired agreement:** each of the eight treatments has exactly one equal
   adjacent event, and all eight repeated representation strings are identical.
2. **ZL-only:** all four ZL treatments have exactly one equal adjacent event
   with the same repeated representation; all four IT treatments have zero.
3. **IT-only:** reverse the preceding condition.

Retain all candidate keys in each group. Select the first key in each group
ordered by integer folio number, recto before verso, then integer locus number.
Do not substitute another key for illegible, ambiguous or unaligned material.
An empty group remains an explicit unfilled selection. Shared sides or scans
remain declared dependencies; the cases are not independent manuscript samples.
Other eligible patterns, including multiple events or policy-sensitive results,
remain listed separately. Selection is purposive and conditioned on encoded
repeat evidence, not a representative prevalence sample.

For each selected locus preserve the complete native source record, physical
source-file line number, alphabet, page variables, all eight token arrays/event
coordinates, and immediately preceding/following native records in each
edition. Numeric locus order does not establish physical writing-row order.

## Image work after selection is frozen

Commit the plan and synthetic-tested selector before its first manuscript
run; commit the resulting selection before inspecting selected image pixels.
Use the saved index's exact Yale canvas/image/service/catalog identities and
native dimensions. Record access date, derivative dimensions and byte hashes
for every inspected image. Reference review rectangles in native image pixels
as `[x,y,width,height]`, upper-left origin. Regions may be chosen after viewing
the fixed pages; region selection itself is not prospective.

Attempt whole-row association using multiple source/context anchors and compare
neighboring placements. Then describe visible shape/spacing correspondence at
the proposed immediate-repeat location, keeping direct pixels separate from
the source-informed inference. Retain contradictory shapes, possible extra
boundaries, alternative placements and failures. Stop at provisional inspection
windows. Do not adjudicate glyph identities, words, edition accuracy, or apply
source corrections. No decoding or translation is proposed.

and other manuscript images. Project inventories and other contributors have

review, independent human observation or untouched evaluation. Later pages and
