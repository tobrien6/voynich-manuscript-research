# Historical H / IT2a record-projection audit plan

This exposed-data follow-up asks which page-level lowercase similarities survive
when native record boundaries and order remain visible. The accepted page
diagnostic already found 183 equal streams, 39 different streams with equal
frequencies, and a separate nonexistent-envelope discrepancy. Those results,
native page/count differences and selected original records have been inspected.
This is an exploratory source audit, not a preregistered decipherment test or
untouched evaluation.

Use the same pinned historical 1.6e6 H records, including padding-only
envelopes, and modern IT2a present records. Keep exact page names and all
unmatched names; never truncate foldout names or apply inferred aliases. Use the
accepted source-specific lowercase projection independently on each body. It
removes human comments/modern metadata and retains only ASCII a–z, so equal
projections cannot establish full text, spacing, unknown signs, glyphs or
physical row identity.

For every page, preserve native record denominators and all empty-projection
locators separately. Compare the ordered **nonempty record-projection list**
and its **multiset**, using exact projected strings before serialization. Also
retain the joined-stream and symbol-frequency comparisons from the parent
diagnostic. Equality of a nonempty bag is null when either side has no nonempty
records. Empty records are never positive matching evidence.

Inventory every shared nonempty projection group per exact shared page, with
its lowercase length/digest and each original historical/modern locator and
source-file line. Record multiplicities. A group with exactly one record per
edition is an unambiguous equality of this lossy projection within that page;
it is **not a verified locator, glyph or region crosswalk**. Duplicate groups
remain many-to-many possibilities; do not pair them by position. Distinct exact
strings with a digest collision must fail rather than silently share a group.
Record projections found only on one side separately with their native locators.
No projected text bodies are copied into the report.

Describe all exact shared pages, then separately report pages with equal bags
but different nonempty record order, and pages whose joined streams agree while
record bags differ. These contrasts can expose what the parent's boundary/order
loss hides; they cannot attribute an original correction or physical layout to
an edition. Do not align unequal record bodies, infer split/merge aliases, or
add nonexistent loci to ordinary analysis content.

Pin both catalogs and original bytes, the parent report and every calculation
dependency. A check must reproduce the complete report with JSON numeric/type
distinctions. Guard source, parent, catalog and implementation paths and their
symlink/hardlink aliases before any output. Preserve input bytes. Use synthetic
examples to verify permutations, duplicate ambiguity, empty records, split/merge
loss, different symbol order, comments/metadata and unmatched/nonexistent cases;
reconstruct real-input results independently. Publish a focused script, tests,
metadata report and credited guide. No manuscript images, source corrections,
translation, source-accuracy ranking or significance test are planned.
