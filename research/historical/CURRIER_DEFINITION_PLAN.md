# Primary-table H notation model plan, version 1

Question: how much native H notation is covered by the independently supplied
Currier/Eva definition, how do its units change notation lengths, and does one
explicit opaque-unmatched parser preserve token equality/repetition?

Publish this plan and a synthetic-tested producer before computing the new H
coverage and converted-length inventory. Full H/source material, accepted
inventory/parsing, approximate assays, pending H/Reddy envelope/type results,
the primary definition and its synthetic string limits are already exposed.
This is a descriptive whole-source model audit, not untouched evaluation.

## Fixed sources and one procedure

Depend on the published primary conversion-source intake in PR #181 at
`a03ac3589bb138be98a701666a481d9d4b1174e6`; require its acceptance before this
follow-up merges. Pin eight source/reader/plan/report dependencies and all three
local rule/manual/README artifact identities. Verify the complete accepted
native H intake and historical parsing reports before applying the model.
Validate every definition-row/column identity and the complete source catalog's
structural and synthetic diagnostic fields. Execute no author program.

Reuse all native H records, source order and the accepted comment/filler/
separator normalization with an empty listed-code set. Retain coded fallbacks,
asterisks, empty records and every token. Apply no manual exclusion, code
deletion, case folding, body repair, alignment or fitted alphabet map. No Reddy
corpus is read, paired, scored or used to tune the model in this experiment.

Use only the pinned definition's Eva right-column strings and Currier
left-column codes. At each original token offset choose the longest matching
right-column string; emit its single left-column code once and advance past
that matched substring. Do not rescan emitted output. If no rule matches, copy
exactly one original codepoint opaquely and flag its original token-local
offset. Never discard it, silently infer a glyph, or replace it with an
asterisk. This is one declared parser model, not full Bitrans emulation.

Output containing unmatched symbols is **partial definition-based notation**,
not certified complete Currier transliteration. The table and parser specify
string units; they do not establish the physical manuscript's glyph units.

## Complete observations and reversibility

Retain every H record descriptor, original ordinal and physical source line,
input/partial-output token-vector hashes, token counts, notation codepoint
totals, token-length sums/distributions and per-record coverage counts. Retain
all unmatched events with local token index, original character offset and
Unicode codepoint; retain every global rule-use count by its definition file
line, including zero-use rules. Account for every input character as part of
exactly one matched span or one opaque unmatched event.

Decode every model-output token by expanding known single Currier codes through
the left-column definition and copying all other codepoints opaquely. Require
exact recovery of the original token. Verify the relevant source-alphabet
condition: every allowed input character that is also a Currier output code
has a single-character Eva rule, so it cannot be emitted as an unmatched
character that the decoder would reinterpret. Together with unique single
output codes, this supports injectivity of this parser on the declared input
alphabet. It does not guarantee arbitrary Currier-string round trips in the
opposite direction, which the source intake already shows can fail.

Keep complete source/output type-frequency and pair-hash ledgers, verifying
the bijection on all input tokens. Record full source/output character
frequencies and equality-edge counts. Separately compute within-record and
flattened-joining A (equal neighboring occurrence edges) and B (distinct types
with at least one such edge), plus scope overlap and all joining boundaries
that span normalized-empty H records. Do not add cyclic edges. These joins are
declared file-stream opportunities, not verified physical adjacency.

## Validation and limitations

Before new source computation, test greedy prefix choices, noncumulative
output, opaque unsupported symbols and asterisks, full decoder recovery,
duplicate/ambiguous/malformed definitions, wrong source identity, every pinned
dependency and complete parent mismatch. Test the input-alphabet proof condition
and source catalog's synthetic failure ledger without treating them as full
program conformance. Validate type/repeat identities using direct original
string equality, including within/joining scopes, naturally empty records and
singleton populations. Protect eight dependencies, both plans, producer and
three local references against early/late direct/symlink/hardlink output aliases.
Preserve existing outputs on serialization/check failures.

Retain all outcomes, especially incomplete coverage. No alternate unsupported
symbol policy is introduced after seeing results. A later Reddy comparison or
revised converter needs a separately frozen model with its exposure declared.
Native H credits/terms remain explicit; source definition/manual/README remain
local under the primary intake's reuse limitation. Publish metadata and
original model code only, without raw corpus bodies or author rule payload.
No historical execution, original-author byte identity, glyph alignment,
language, calibrated statistical tail, decipherment or translation is claimed.
