# Native projected-record order: descriptive plan

Question: how much exact projected-record agreement can be retained in both
native source orders on the accepted equal-multiset pages? This diagnostic
quantifies an ordering obstruction before any historical/modern row crosswalk.
It does not choose a source order or change native records.

## Statistic and duplicate handling

Let A and B be those nonempty sequences and n their common multiset size.
Compute L, the length of a longest common subsequence (LCS) under exact projected
string equality. Report L and n-L: the minimum unmatched records **per source**
in any maximum-cardinality pairing that preserves both native orders. Also
report 2(n-L), the total unmatched records across the two equal-length sequences.
These are combinatorial sequence quantities, not physical deletion proposals,
edit-history estimates, glyph accuracy, or fitted manuscript distances.

Use exact integer prefix and suffix LCS tables. Retain every candidate index
pair (i,j) that can occur in at least one maximum pairing: A[i]=B[j] and
prefix[i,j]+1+suffix[i+1,j+1]=L. Its matched rank is prefix[i,j]+1.
An index pair is mandatory across all maximum pairings exactly when it is the
sole candidate at its rank; otherwise retain all candidates at that rank.
Do not emit an arbitrarily selected maximum pairing. Distinct native records
with the same lossy projected string remain observationally indistinguishable;
the complete candidate inventory exposes that ambiguity. A pair being mandatory
in this computation never makes it a verified historical/modern locator alias.

For every order-different page publish both ordered nonempty descriptor lists,
their projection lengths/digests, all candidate index pairs and ranks, mandatory
pair flags, rank candidate counts, and empty descriptors. Report all 29 pages
in the guide rather than selecting a favorable example. Equal-order controls
must have L=n and only identity index pairs; verify and retain their page IDs.
No random shuffle, calibrated tail, language or manuscript mechanism is tested.

## Validation and prior exposure

Before real-data measurement, verify the pure LCS/candidate/mandatory formulas
against exhaustive index-subsequence alignment enumeration on small synthetic
sequences, including reversals, swaps, repeats, unequal lengths and empty input.
Verify typed full-report replay, source identities and all native descriptor
coverage. Protect sources, catalogs, accepted report/plan, implementations and
check inputs from direct/symlink/hardlink output aliases before computation and
again after serialization; a failed check must preserve an output destination.

The accepted 211/182/29 split, all 29 page IDs, prior parent summaries, native
source bodies and selected image contexts have already been exposed. Publish
this plan before implementing or measuring the new statistic, without claiming
an untouched evaluation or independently certified inspection chronology.
The sequence diagnostic supplies no physical row alignment, full-body/glyph/word
identity, source preference, statistical-use eligibility or decipherment.
