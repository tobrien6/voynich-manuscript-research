# Fixed comparisons for the four unmatched f101 page identifiers

The accepted [record-projection audit](RECORD_PROJECTIONS.md) leaves historical
H `f101r1` / `f101v2` and modern IT2a `f101r` / `f101v` unmatched. This follow-up
will compare every pair in that fixed two-by-two family without changing any
source identifier or the parent's 223 exact-page comparisons. The four names
and aggregate parent findings were already inspected. The entire source corpus
and selected earlier source records were exposed. There is no untouched test,
preregistration or decipherment claim.

Freeze the [machine plan](f101-candidate-plan.json) before calculating this
candidate matrix. Reuse the accepted catalogs, native readers and source-specific
ASCII a–z projection, including their losses of case, spacing, uncertainty,
metadata and notation. Verify every frozen dependency and reproduce the complete
accepted parent report before extracting records. Select all H records and all
present IT2a loci with the four literal page IDs; preserve native denominators,
empty projections, source order and file lines. Fail if these cease to be the
parent's complete unmatched page sets.

For all four pairs, compare exact nonempty ordered projection lists, multisets,
joined streams and symbol frequencies. Retain every shared and one-sided nonempty
projection group with all native locators, source-file lines, units/kinds and
page-order indices. Preserve duplicate multiplicities without choosing a pairing.
Report exact equality before digest serialization and reject collisions between
distinct strings. Empty projections cannot be positive matches; comparison flags
are null if either side has no nonempty records. Publish lengths/hashes and source
locators, without copying source bodies or projected strings. Both opposite-side
comparisons remain in the matrix regardless of their results.

All candidate pairs remain unaccepted aliases. No truncation, page rename,
record reordering, preferred candidate, image region, glyph adjudication, source
correction, statistical inclusion or translation follows. Related editions and
lossy equalities are dependent source evidence. The parent report and scientific
inputs must remain byte-identical. A later convention/image study would have to
establish physical correspondence separately.

Validate source selection, all four retained comparisons, permutations, split
records, duplicate/empty groups, collision failure and output preservation with
synthetic tests before real calculation. Check complete JSON with numeric/type
distinctions and duplicate-key rejection. Protect frozen files, sources, plans,
implementation and check targets from direct/symlink/hardlink output aliases
before calculation and after serialization. Independently reconstruct the four
page selections and full candidate results from the pinned raw sources.
