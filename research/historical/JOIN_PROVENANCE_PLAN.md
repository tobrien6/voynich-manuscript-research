# Native-record equal-join provenance plan, version 1

Question: which exact native H records form every equal-token joining event in
the four accepted approximate historical streams, and do excluded or empty H
records lie between those endpoints in source order?

This is a descriptive provenance census, not a new null, significance test or
decoding hypothesis. The global assay already exposes 9/10 equal joining events,
6/7 repeating joining types and five types also repeating within records. All
input/source/parser material and the conditional mean comparison in PR #131
are already exposed. Exact event identities and their source-order contexts
will be inventoried after this plan and synthetic validation are committed.

## Fixed input and complete population

Pin the accepted global assay's twelve source/method/report dependencies at its
repaired head. Reconstruct all four parser variants unchanged and require exact
parser report and record/flat digest replay. Match all observed A/B and boundary
diagnostics against the accepted global report before collecting cases.

The edge population remains every join between consecutive nonempty retained
H records in the surviving flat stream. Empty/excluded records contribute no
tokens but retain their original H order positions. Do not create a cyclic
closing edge, drop native labels, merge duplicate strings, alter gap slots or
choose cases by image availability.

Count every joining edge in three disjoint native-envelope categories:
same page/same unit, same page/different unit, different page. Independently
count directly consecutive selected H records versus joins spanning intervening
empty/excluded H records. Report the same two classifications for all equal
joining events, so denominators and classifications reconcile.

## Every observed equal joining event

Retain the endpoint token and complete descriptors for both records: native
locator, page/unit/line strings, zero-based selected-H source ordinal, one-based
physical source-file line, raw body SHA-256, normalized token count before manual
exclusions, retained token count and endpoint's pre-manual normalized index.
Record all intervening selected H records with their descriptors, original
normalized count, empty retained stream and every recorded exclusion reason.
The H ordinals ignore records under other transcriber codes; physical file-line
distance is a separate source diagnostic, not a manuscript line distance.

Keep cases in native stream order for each variant. Count repeated joining
types once and retain their overlap with within-record repeats; mark that
overlap on each event. Retain all four matrices even if their event lists agree.
Require case counts, joining type counts, shared type count and total joining
edges to reproduce the accepted report. Record source credit/permission and all
producer/plan/dependency fingerprints. Endpoint tokens are source-derived
notation with the publisher's reuse terms, not newly decoded words.

## Validation and limits

Before manuscript census, test direct and bridged joins, intervening whole-record
exclusions versus naturally empty records, within/joining type overlap,
case-sensitive identity, empty streams, noncyclic endpoints, classification
denominators, record/order/endpoint-index and corpus/report mismatch failures.
Check direct/symlink/hardlink aliases to every protected dependency/plan/producer
before computation and immediately before writing, including aliases introduced
during computation; failures preserve existing output.

Native locator categories and selected-source adjacency do not establish physical
manuscript lines, image regions, word/glyph boundaries, textual continuity or a
historical-author input. The census must not silently create an H/modern crosswalk
or assign duplicate projections from PR #135. Image review and verified alignment
remain separate work. Keep parser/count/label discrepancies and the measured
global/conditional edge scopes intact. Any new statistical or mechanism test
requires another explicit plan.
