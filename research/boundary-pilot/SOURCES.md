# Sources for the section boundary survey

All four sources were inspected on 2026-10-11 (America/New_York).

| Source | Use in this survey | Limitation |
| --- | --- | --- |
| [Beinecke manuscript overview](https://beinecke.library.yale.edu/beinecke/collections/beinecke-cipher-voynich-manuscript) | Six broad subject categories | Descriptive subject names do not decode the writing. |
| [MS 408 manuscript catalog](https://pre1600ms.beinecke.library.yale.edu/docs/pre1600.ms408.HTM) | Section ranges used to choose boundary targets | The ranges are catalog attributions, not page-level classifications established by this survey. The catalog warns that foldout foliation is inconsistent. |
| [Yale digital collection record](https://collections.library.yale.edu/catalog/2002046) | Image viewer, object identity, access and rights metadata | A browser visit succeeded; an automated web fetch returned HTTP 503. Public availability alone does not identify an open reuse license. |
| [IIIF Presentation 3 manifest](https://collections.library.yale.edu/manifests/2002046) | Canvas labels and identifiers, original image sizes, IIIF image service links | No explicit edition identifier was supplied. Shared and partial canvas labels require preservation. The manifest repeats catalog metadata and is not independent evidence for its historical claims. |

The downloaded manifest contains 213 canvases, including covers and other non-folio views; this is not a leaf count. Its response-byte SHA-256 is `317d58fd9ea90392a83d9858a91eada3d0b41416a3c835857dc0154bd123a309`. [Selection metadata](selection.json) retains the ten selected mappings. Canvas indices describe the retrieved order and can change; use the recorded IDs and labels as well.

The digital collection records public access and a caution about copyright, site licenses and other rights. This contribution publishes source links, selected technical metadata, and original descriptions; manuscript image files are not redistributed. The inspected derivatives use each recorded image service followed by `/full/!1600,1600/0/default.jpg`.

Suggested citation: Cipher manuscript (Voynich manuscript). General Collection, Beinecke Rare Book and Manuscript Library, Yale University, Beinecke MS 408, object 2002046; include the specific folio and canvas from the [inventory](INVENTORY.md).
