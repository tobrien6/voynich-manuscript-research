# Pilot folio inventory protocol

## Question and scope

How do text placement and visible illustration forms differ across a small sample of the six sections in Yale's description of Beinecke MS 408?

This selection rule was saved locally on 2026-10-11 before inspecting the selected manuscript images. It is a documented sampling decision, not an independently timestamped public preregistration. The outcome is a descriptive inventory, with no transcription or decipherment claim.

## Selection rule

Use the section ranges in [Yale's manuscript catalog](https://pre1600ms.beinecke.library.yale.edu/docs/pre1600.ms408.HTM) (S002). Allocate two entries each to Parts I, II, III and V, and one each to IV and VI. For the four two-entry sections, select the first and last surviving recto in the stated range. For VI, select its first recto. For IV, select the recto included in the complete foldout scan: the manifest labels this `85v and 86r (foldout)`. The full foldout permits a layout observation while retaining its joint folio label.

| Catalog part | Catalog range | Target folio sides |
| --- | --- | --- |
| I botanical | 1r–66v | 1r, 66r |
| II astronomical or astrological | 67r–73v | 67r, 73r |
| III biological in the catalog; balneological in the overview | 75r–84v | 75r, 84r |
| IV cosmological foldout | 85r–86v | 86r, scanned with 85v |
| V pharmaceutical | 87r–102v | 87r, 102r |
| VI text with marginal stars | 103r–117v | 103r |

Map these ten targets to [Yale's IIIF manifest](https://collections.library.yale.edu/manifests/2002046). Prefer an exact target label; otherwise use the first canvas in manifest order whose label explicitly contains the target. Retain the entire label when it mentions another side or a partial view. For IV use the complete foldout label above rather than a partial exterior view. Do not replace unusual images after inspection.

These are ten target folio sides, not ten uniformly sized physical leaves or isolated scan panels. Shared canvases must not later be counted as independent images or assigned wholesale to one target folio.

## Observation method

Inspect each selected canvas at overview resolution and consult a larger image where necessary. Record the target folio, full Yale canvas label, zero-based canvas index, persistent canvas and image links, catalog classification, visible text arrangement, illustration forms, and uncertainties. Image descriptions are direct visual observations; section names are source statements. Avoid identifying plant species, translating glyphs, or treating an illustration's apparent subject as proof of the text's meaning.

Use qualitative layout descriptions. Do not estimate glyph, token or line counts from overview images. Record partial and shared scans explicitly. Publish links and metadata, not image copies.

## Limitations and next test

The sample emphasizes boundaries, allocates unequal fractions of the sections, and includes only rectos plus the other side visible in the selected foldout. It cannot estimate manuscript-wide frequencies. A later sample should include interior folios and versos, use independently reviewed panel boundaries, and compare manual layout annotations before choosing transcription units.
