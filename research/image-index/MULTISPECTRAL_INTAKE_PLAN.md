## Evidence to retain

For each selected file record its public ID/view/download link, exact name,
parent folder, source label, bytes, SHA-256, decoded format/mode/dimensions,
and only non-sensitive technical metadata needed for interpretation. Verify
actual file signatures rather than treating an HTML download response as an
image. Report byte-identical copies across folders explicitly.

Describe observable writing, crop/orientation and background/show-through
differences across all selected views. Preserve negative/ambiguous cases. Do
not tune colors, contrast, transforms, geometry or a glyph mapping after looking.
Full-frame thumbnail rendering may reduce display resolution; original bytes
remain available locally for inspection. New zoom views must cite the original
file and pixel window, without manufacturing enhanced image evidence.

Keep source statements, direct observations and interpretation separate. These
are nonblind observations by one assistant after reading an expert's discussion.
Agreement does not become independent qualified paleographic review. Multiple
processed images of one surface do not create new manuscript samples. More
visible marks do not establish a glyph, author, date, cipher key or translation.

In particular, `116v` usage or visible resemblance does not resolve what the
legacy catalog meant by `117v`. Keep the alias registry unresolved. Numeric
components in filenames do not authorize coordinate transfer between captures;
foldout/panel names remain separate from Yale whole-canvas labels.
