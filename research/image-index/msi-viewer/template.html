Source identity and coordinate conventions

Original file bytes are checked before display. The viewer removes the EXIF segment only from an in-memory decoding copy, verifies the resulting digest, and applies orientation explicitly. JPEG coding/scan data and ICC profiles remain intact. Original files are unchanged. Browser color management and resampling may affect the screen display.

Coordinates use zero-based pixel indices. For orientation 3, a displayed pixel (x,y) corresponds to stored (width−1−x,height−1−y). No coordinates are transferred between separate captures.
